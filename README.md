# Kanban Board

A personal kanban board for software development work.

Stack: Next.js, Convex, Clerk, shadcn/ui, Tailwind CSS, hosted on Vercel.

This project starts at the bare minimum and grows one issue and pull request at a time.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Status

Scaffold only. First version: buckets (columns) of task cards, where a card has a title and a checklist, with add, move, edit and delete.
